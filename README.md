# RWA.ltd Homepage Redesign

Responsive frontend UI demo for the RWA.ltd homepage.

## Scope

- Desktop homepage UI
- Mobile responsive layout
- Static frontend demonstration
- No API, authentication, KYC, wallet, payment, or trading integration

## Preview

Open `index.html` in a browser.
